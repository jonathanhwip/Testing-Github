# Testing-Github

A tiny demo website used to learn how GitHub works.

## What's here

- `index.html` – the web page
- `style.css` – how the page looks (colours, spacing, dark mode)

## How to view it

Download the project (green **Code** button → **Download ZIP**), unzip it, and double-click `index.html` to open it in your browser.

## See it live

The page is online at **https://jonathanhwip.github.io/Testing-Github/** (hosted for free by GitHub Pages).
