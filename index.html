Hello, GitHub 👋

This little page was built to show how GitHub works.

What you're looking at

  • Branch – a safe copy of the project where changes are made.
  • Commit – a saved snapshot of a change, with a note explaining it.
  • Pull request – a request to bring the branch's changes into the main project.
  • Issue – a to-do item or idea, tracked in one place.

Made as a GitHub demo.
